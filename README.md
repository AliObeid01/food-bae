# Food Bae

Responsive restaurant website with home, menu, about and contact pages.

**Live demo:** https://food-bae-lb.vercel.app/

## Features

- Home, Menu, About and Contact pages with client-side routing
- Responsive layout built with Tailwind CSS
- Page and element animations with Framer Motion
- Deployed on Vercel

## Tech stack

- React 19 and React Router 7
- Vite 7
- Tailwind CSS 3
- Framer Motion
- Lucide and React Icons

## Getting started

```bash
git clone https://github.com/AliObeid01/food-bae.git
cd food-bae
npm install
npm run dev
```

Other scripts:

| Command | What it does |
|---|---|
| npm run build | Builds the production bundle |
| npm run preview | Serves the production build locally |
| npm run lint | Runs ESLint |

## Project structure

```
src/
  assets/       images and static assets
  components/   shared UI components
  context/      React context providers
  data/         site content
  hooks/        custom hooks
  pages/        Home, Menu, About, Contact
  App.jsx       routes
  main.jsx      entry point
```
